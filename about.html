About PantryBook

PantryBook is a final internship project: a responsive recipe manager that lets a home cook save, search, filter and edit their own recipes, entirely in the browser.

Why this project

Family recipes usually live scattered across notebooks, screenshots and chat messages. PantryBook gives them one searchable home, with the kind of add / edit / delete workflow used in most real content-management tools.

What it demonstrates

  • Semantic HTML — header, nav, main, aside, section, article, footer, and an accessible form with labelled fields.
  • CSS — the box model, Flexbox for the header and filter controls, CSS Grid for the recipe cards, and media queries for phone, tablet and desktop layouts.
  • JavaScript — an array of recipe objects, DOM rendering, event handling (search, filter, sort, form submit, click-to-edit, click-to-delete), and browser storage so data survives a page reload.

How to use it

  1. Open the Recipe Box page. A starter set of recipes loads automatically the first time.
  2. Use the search box or the course / difficulty filters to narrow the list.
  3. Click a recipe card to see the full ingredient list and method.
  4. Use + Add recipe to create a new one, or the edit / delete icons on a card to manage existing ones.

Tech stack

HTML5, CSS3 (Flexbox, Grid, media queries, custom properties) and vanilla JavaScript (ES6). No frameworks or build step — open index.html and it runs.

PantryBook — built as a frontend project . Data is stored locally in your browser.
